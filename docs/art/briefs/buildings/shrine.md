# Brief: Shrine (`shrine`)

2 × 2, service coverage 14, +1 culture. 1 Settler. Hearth & Shrine.

## Silhouette

White plaster cell + stone cap + offering forecourt. Smallest civic.

```
        ___
       /___\         stone cap 30°
       |   |         plaster cell, one dark door
       |_#_|      offering bowls ->
```

Plan: cell N, forecourt S with bowl row and one lantern post.

## Roof, materials, tokens

- Walls `wall.plaster` (brightest walls on the island), cap `roof.stone`.
- Signature props: **offering bowls** (3, `pottery.glaze`, flame dots when
  tended) + lantern post (`wood.beam.dark` + paper.highlight lamp).

## Island-zoom read

White cube + stone cap. A landmark by brightness, not size.

## States

- Working: bowl flames lit, door open, garland (green dots) on lintel.
- Idle: flames out, door shut.
- Paused: standard tarp (covers forecourt, cell shows — reverence exception).
- Construction: standard scaffold at small scale.

## Upgrade hook (M2-30)

None; later eras add new worship buildings, never a variant of this cell.
