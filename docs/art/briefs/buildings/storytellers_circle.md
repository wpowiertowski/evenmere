# Brief: Storyteller's Circle (`storytellers_circle`)

3 × 3, +3 culture, 1 creativity/day (Folk Epics), 1 Writing slot. 2 Villagers.
Oral Tradition.

## Silhouette

No roofed mass: ring of log benches around a fire pit + one carved story post.

```
      (bench)(bench)
     (  fire pit  )       pit: stone ring + logs
      (bench)(post)       post 3 m, carved rings
```

Plan: circle centred, post N, benches ring, brazier spare at gate.

## Materials, tokens

- Benches `wood.bark.dark` logs; pit ring `stone.mid`; post `wood.beam.dark`
  with `ink.strong` carved rings; ground worn `field.fallow` disc.
- Signature props: **story post** + fire (flame + smoke = active telling).

## Island-zoom read

Bare ring + single post. The only building with no roof; reads by absence.

## States

- Working: fire lit, benches occupied (blanket dots `ui.accent`), smoke.
- Idle: fire cold, benches empty.
- Paused: standard — tarp over the benches (post shows).
- Construction: post raised first (ceremony), then benches.

## Upgrade hook (M2-30)

None; the Guildhall/Theatre (Era II) supersede by succession, not variant.
